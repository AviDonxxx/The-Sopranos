## Что сделано на текущий момент (Этап 2)

1. **Единый источник контента:**
   - Каталог `content/` является единственным местом редактирования уроков.
   - Создан `scripts/sync-content.js`, который автоматически синхронизирует `content/` в `public/content/`.
   - Добавлен хук `"prebuild": "node scripts/sync-content.js"` и команда `"sync": "node scripts/sync-content.js"`.
   - В `.gitignore` добавлена строка `public/content/`.

2. **Страница урока (`src/pages/LessonPage.jsx`):**
   - Уроки загружаются из `public/content/lessons/` по списку `content/steps.json`.
   - Markdown рендерится через `marked` и очищается `DOMPurify`.
   - Если урок отсутствует или находится в разработке (шаги 26–75), отображается карточка «Урок готовится» без сбоя в навигации.
   - Блок «**Ответы:**» вынесен в раскрывающийся спойлер `<details><summary>Показать ответы</summary>...</details>` (по умолчанию закрыт).
   - Внизу расположены кнопки «Назад» (кроме шага 1) и «Дальше» (кроме шага 75).
   - При переходе на новый шаг страница автоматически прокручивается к началу (`window.scrollTo(0, 0)`).

3. **Прогресс и подсказки (`src/context/ProgressContext.jsx`):**
   - Добавлена кнопка «Отметить как понятое» (повторный клик снимает отметку).
   - Если предыдущий шаг не пройден, отображается мягкая рекомендация со ссылкой («Рекомендуем сначала пройти предыдущий шаг»), не блокирующая прохождение.
   - На главной странице выводится строка «Пройдено: N из 75», а пройденные шаги помечаются зелёным бейджем.
   - Прогресс сохраняется в `localStorage` по ключу `math-zero-progress` и сохраняется при перезагрузке.
