# Правила для будущих сессий (ОРТ-тренажёр)

Обязательно читай перед началом любой сессии.

## Основные правила

1. **Сначала читай `PLAN.md`.** Он содержит статус задач, принятые решения и список файлов.
2. **Одна задача за сессию.** Выбирай одну строку со статусом `todo` из PLAN.md и завершай её, прежде чем брать следующую.
3. **Обновляй статус после работы.** Как только задача сделана — пометь её `done` в `PLAN.md` и кратко опиши, что изменено.
4. **Не выходи за рамки текущей задачи.** Логику пиши только для текущей стадии; не anticipated-реализуй будущие этапы.
5. **Следуй структуре:** данные — в `data/`, импорт — в `scripts/seed.js`, валидация — в `scripts/validate.js`, миграции — в `supabase/migrations/`, фронтенд — в `src/`.
6. **RLS и безопасность:** Subjects/topics/questions — публичное чтение; Attempts — вставка для всех, чтение только своих (`auth.uid() = user_id`).
7. **Язык интерфейса:** ru / ky. В данных есть поля `_ky` для кыргызской версии.

## Команды

- `npm run dev` — запуск
- `npm run validate` — проверка данных
- `npm run seed` — импорт в Supabase
