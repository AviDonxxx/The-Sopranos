# Шаг 11. НОД и НОК

**Главное:** НОД — наибольший общий делитель, самое большое число, которое делит оба числа без остатка. НОК — наименьшее общее кратное, самое маленькое число, которое делится на оба числа.

**Пример НОД:** делители 8: 1, 2, 4, 8. Делители 12: 1, 2, 3, 4, 6, 12. Общие: 1, 2, 4. Наибольший — 4. Значит, НОД(8, 12) = 4.

**Пример НОК:** кратные 3: 3, 6, 9, 12, 15… Кратные 5: 5, 10, 15, 20… Первое общее — 15. Значит, НОК(3, 5) = 15.

## Частая ошибка

Путают НОД и НОК. Вспомните: НОД меньше или равен каждому из чисел, а НОК больше или равен каждому из них.

## Проверь себя

1. Чему равно НОД(6, 9)?
2. Чему равно НОК(2, 4)?

---

**Ответы:** 1) 3. 2) 4.
